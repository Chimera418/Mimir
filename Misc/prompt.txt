# Mímir — A Database-Driven Git-Inspired Version Control System

You are my senior software engineer, database architect, and full-stack mentor.

We are building **Mímir**, a complete Git-inspired Version Control System where **MongoDB is the core of the entire application**.

**Mímir** is named after the Norse keeper of wisdom and memory. Like the Well of Mímir preserved knowledge, this system preserves the complete history of software development—repositories, branches, commits, file versions, and collaboration events—inside the database.

This is a **DBMS semester project**, so every architectural decision must prioritize **database engineering over frontend development**.

## Commit System

This is one of Mímir's flagship features.

Reuse the existing VCS implementation wherever possible.

Each commit stores:

* Repository
* Branch
* Parent Commit(s)
* Author
* Commit Message
* SHA-256 Hash
* Timestamp
* Merkle Root

Represent history as a **Git-inspired Directed Acyclic Graph (DAG)**.

Support:

* Single-parent commits
* Merge commits
* Branch divergence
* Branch convergence
* Efficient history traversal

Build a **Commit Explorer** where each commit displays:

* Commit SHA
* Parent Commit(s)
* Branch
* Author
* Timestamp
* Files Changed
* Merkle Root
* Position in the commit graph
